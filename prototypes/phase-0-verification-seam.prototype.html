Can one root command prove the workspace contract?

This demo tests the proposed verification model before the real workspace exists. Introduce architecture and quality failures below and watch which layer rejects them. The decision is whether this split is small, legible, and strong enough to hand to implementation.

Proposed seam

A contributor and CI both run one repository command. The command keeps the ADR 0010 contract in one root-owned module, then delegates execution facts to their native tools.

pnpm verify node tools/verify-workspace.mjs turbo run build typecheck vitest run ultracite check .

verify-workspace.mjs owns structure and dependency policy only. It does not wrap TypeScript, Vitest, Turbo, Oxlint, or Oxfmt.

Minimal machinery

  • One root contract lists the exact nine workspaces and their permitted edges.
  • One root export smoke test imports every intended public entry point.
  • Shared root TypeScript, Vitest, Oxlint, and Oxfmt configuration.
  • Thin build and typecheck scripts expose Turbo's package graph.
  • No package-local lint, format, boundary, or configuration layer.

Guided walkthroughs

One command, no hidden setup

Start from the settled nine-workspace graph. The architectural contract runs first, Turbo follows internal package edges, and repository-wide quality checks run once.

Make the control plane reach into Worker code

ADR 0010 forbids this even if TypeScript could compile it. The root contract should stop before the build, naming the illegal edge rather than reporting a secondary error.

Drift between source and the published surface

The structural contract checks that an export is declared. The smoke test proves that the declared entry point actually resolves. These are different failures and should stay owned by different checks.

Keep generic tools visible

A formatting failure should still read as an Oxfmt failure. The root seam sequences tools but does not translate or hide their output.

Decision to make

If this prototype feels right, the implementation handoff can be explicit about three constraints. If one feels wrong, that is the useful finding to feed back into the map.

One public entry point pnpm verify is the clean-clone and CI seam.
One architecture source The nine-node allowlist is defined once in a root contract module.
Native tool ownership The seam sequences checks without wrapping or duplicating their behavior.
